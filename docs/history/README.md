# docs/history — superseded planning documents

Documents kept for the record, **not** as open work. Each one was written as a
live checklist, shipped differently or got overtaken, and now opens with its own
STALE banner saying so.

They live here rather than in `tools/` because a checklist sitting next to the
code it describes reads as actionable no matter how loud the banner is — which
is exactly how a "do not treat as an open checklist" file gets treated as one
(B12, 2026-08-25). Deleting them would lose the reasoning behind decisions the
current tooling still reflects, so they are archived instead.

For current state, read the tool's own README under `tools/<name>/`.
